VencordCustom
=============

Vencord with extra, self-made plugins.

Install:   double-click install.bat
Uninstall: double-click uninstall.bat

If you have more than one Discord installed (Stable, PTB, Canary),
the installer asks which one to use - or pick "A" for all of them.

After installing:
1. Start Discord
2. Settings -> Vencord -> Plugins -> enable "PluginHub"
3. Restart Discord (Ctrl+R)
4. A grid icon ("My Plugins") appears at the top left of the title bar.
   There you can turn each of the custom plugins on and off
   and open their settings.

Included plugins:
ChatPopout, FakeMute, FormatHub, GofileUpload, HomeOrganizer, LinkCards,
MediaGallery, ModKit, OpSec, PluginHub, Radar, RamSaver, ServerDeclutter,
ServerTools, SplitView, StreamOverlay, ToolbarManager

Updates: The plugins update themselves. When a new version is out,
Vencord downloads it when Discord starts and asks you to restart.
(Settings -> Vencord -> Updater: keep "Automatically update" on.)

Note: When Discord updates itself, you may have to run install.bat again.
Your existing Vencord settings are kept.
